# TENGU’S — Рейтинг, версия 2

Готовый автономный файл: `dist/tengu-rating-v2.html`. HTML содержит React, CSS, JavaScript и шрифты. Внешних запросов при открытии нет. Требуется JavaScript. Размер — около 0.7 МБ.

## Подключённые библиотеки и исследование

Проверены официальные материалы проектов в интернете и peerDependencies npm. Сайты документации radix-ui.com, motion.dev и lucide.dev в этой среде вернули 403; использованы официальные исходные README на GitHub. Источники прочитаны 13 октября 2026 года.

| Проект | Источник | Решение |
| --- | --- | --- |
| Radix Primitives | https://github.com/radix-ui/primitives#readme | Установлен `@radix-ui/react-dialog@1.3.1`: диалог, Escape, фокус и доступные названия. Оформление через CSS Modules. |
| Motion | https://github.com/motiondivision/motion#readme | Установлен `motion@14.1.1`: короткое появление содержимого карточки, `MotionConfig reducedMotion="user"`, `useReducedMotion`. Декоративный пьедестал статичен. |
| Lucide React | https://github.com/lucide-icons/lucide/tree/main/packages/lucide-react | Установлен `lucide-react@1.56.0`: настоящие React-компоненты Bell, Trophy, Map, ShoppingBag, UserRound, X, ChevronRight. Единые пропорции и толщина линий. |
| shadcn/ui | https://github.com/shadcn-ui/ui#readme | Рассмотрен как набор настраиваемых компонентов. Для текущего небольшого макета достаточно Radix и существующей UI-системы; дополнительный набор оформленных компонентов не установлен. |

Все установленные UI-пакеты декларируют совместимость с React 19. Установлены React / React DOM 19.3.0, TypeScript 5.9.3, esbuild 0.28.2. Точные версии и integrity-записи — в `package-lock.json`. Пакеты находятся в папке этого прототипа, не в репозитории сайта. Библиотеки обеспечивают иконки и поведение; композиция, цвета, шрифты и отступы настроены по брендбуку и замечаниям клиента.

## Шрифты и визуальные изменения

Использован именно `Manrope-VariableFont_wght.ttf` из присланного `Manrope.zip`. Проверены кириллица и диапазон веса 200–800. Заголовки и имена — 800, основной текст — 500. Лицензия OFL сохранена в assets и включена в HTML-комментарий готового файла. Архив также содержит статические начертания, но для одного автономного файла достаточно variable font.

Archivo из действующего сайта оставлен только для воспроизведения текущего логотипа. В реальном проекте сохранить оригинальный компонент/векторный логотип. Основной интерфейс использует присланный Manrope.

- Логотип 22 px; название лиги — 36 px (34 px на 320 px, 44 px от 701 px).
- Имена — 16 px, на узком экране 15 px. Основной текст и вкладки — 14 px, показатели — 12 px (11 px на 320 px, 13 px на широком экране).
- Очки — 22 px, на узком экране 20 px, на широком 24 px. Суффикс «очк.» на мобильном под числом: имена получают больше места.
- Логотип уменьшен, баланс очков из шапки убран. В таблице очки сохранены.
- «Лиги / Встречи / Кланы» над заголовком. «Рейтинг» — название раздела в основной навигации, внутри используются понятия лиги.
- Пьедестал 2–1–3: только круги, никаких шестигранников, звёзд и замков. Золотой круг 97 px, серебряный и бронзовый 83 px. Вертикальные металлические градиенты уходят вниз в прозрачность. Круги декоративные, не кликабельны.
- Металлические рамки имеют мягкий градиент. Не используются конфетти, непрерывное мерцание или пульсация.
- Убраны звёздочка перед уровнем и стрелка перед навыком, включая уточнённый комментарий справа в документе.
- В строках сохранены круглые аватары и медали топ-3. На золотой медали тёмная цифра для читаемости. На серебре и бронзе цифры белые, 20 px / 800.
- Зона повышения и граница после пятого участника. У собственной строки тёплая подложка, красная линия и подпись «Вы».
- Спокойные фон и карточки из существующего интерфейса: #F5F3F0 / #FBFAF8; фирменные #C60814 и #272F37. Скругления вкладок 18 px, кнопок 13 px, рейтинга 21 px.
- На компьютере заголовок и пьедестал расположены рядом, навигация — слева. На смартфоне — одна колонка и фиксированное нижнее меню с safe area.

## Данные и ограничения

Учтены шесть исходных замечаний, визуальный референс и все дополнительные ответы пользователя. Показана только активная лига. Имена, порядок и показатели — демонстрационные данные из документа. «Вы» у jukabernik — состояние примера, не текущего авторизованного аккаунта. При предыдущем осмотре живого сайта аккаунт находился в резерве; активный рейтинг вживую не был доступен.

Фотографий участников нет: показаны инициалы. Компонент `Avatar` принимает `avatarUrl` и возвращается к инициалам, если фото отсутствует или загрузка завершилась ошибкой. В production подставить реальные разрешённые URL. Не заменять фотографии выдуманными портретами.

Строки открывают демонстрационную карточку участника. Остальные разделы сообщают об ограничениях прототипа; в приложении сохранить реальные маршруты и существующие карточки. Срок «3 дн.» статичен; в приложении использовать реальное серверное время. Алгоритмы начисления очков, сортировки и перехода между лигами не менялись.

## Передача разработчику

Исходный компонент — `src/Rating.tsx`, оформление — `src/Rating.module.css`. В Next.js компонент остаётся клиентским. `src/main.tsx` — точка входа только автономного макета, её не переносить в Next.js. В production подключить Manrope через существующий механизм local fonts / next/font, переиспользовать навигацию, логику встреч, уведомления и данные API. Не переносить статический массив `participants` как реальные данные.

Пересборка из этой папки:

```sh
npm ci
npx tsc
npm run build
```

Исходники самодостаточны: все используемые шрифты находятся в assets. `dist/build-meta.json` подтверждает включение Radix, Motion и Lucide в сборку. Содержимое `node_modules` в передаваемый архив не включено.

## Проверка

- TypeScript 5.9.3: без ошибок.
- Chromium: 320, 360, 390, 430, 768, 1440 px, горизонтального переполнения нет.
- Шрифты загружены из HTML, внешних HTTP-запросов и ошибок JavaScript нет.
- Открытие/закрытие Radix Dialog, Escape, удержание фокуса и возврат фокуса к исходной строке проверены.
- Проверен `prefers-reduced-motion`, длинное имя и доступность последней строки над нижним меню.
- Размеры областей нажатия видимых активных элементов не меньше 44×44 px.
- Изображения превью предназначены для внутренней визуальной проверки. Сам HTML работает без них.

Это проверка автономного макета. Физические телефоны, WebKit и интеграция с сервером не проверялись. Сайт не изменён, файл на Google Drive не загружен. Ссылки на workspace открывают файлы среды; возможность скачивания через интерфейс пользователя не подтверждена.
