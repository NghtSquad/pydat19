# TENGU’S — рейтинг по уточнённому визуальному эталону

## Текущий статус

Геометрия и оформление обновлены по новому скриншоту и CSS действующего сайта. Замечание клиента об удалении звезды уровня и стрелки навыка повторно подтверждено и соблюдено.

**Аватары ещё не встроены.** Три изображения показаны в сообщении, но не доступны как файлы в рабочей среде. Для завершения нужны исходные изображения (удобно одним ZIP). Сейчас остаются инициалы. Предложенный порядок: кот — первое место, персонаж с птицей — второе, портрет — третье. Окончательное соответствие эталону и проверка настоящих изображений пока не выполнены.

## Что восстановлено

- Компактный логотип, вкладки над названием лиги, подпись «Твоя лига», название «ЖЕЛТАЯ».
- Шрифтовая цепочка текущего сайта: ArchivoTengus / Manrope. Для заголовка и логотипа — Manrope из присланного архива. Шрифты встроены в автономный HTML.
- При ширине 390 px: боковые поля 22 px, переключатель высотой 50 px, строки рейтинга 67 px, медали 32 px, аватары в списке 42 px.
- Пьедестал высотой 108 px: победитель 69 px, остальные 65 px; однотонные металлические обводки и направленные вниз градиенты. Цифры под аватарами убраны. Круги остаются декоративными.
- Карточка рейтинга начинается приблизительно на 285 px от верха страницы при ширине 390 px. Системная строка iPhone с временем не воспроизводится в HTML.
- Очки и «очк.» снова стоят в одну строку; золотая, серебряная и бронзовая медали с белыми цифрами — по образцу.
- Собственная строка выделена бежевым фоном и отметкой «Вы», без добавленной ранее красной полосы.
- Зона повышения снова одной строкой, граница после пятой строки; никакой новой компоновки блоков на мобильном экране.
- Звезда уровня и стрелка навыка отсутствуют. Число навыка имеет доступную подпись для экранного диктора.

Остальные библиотеки и принцип сборки сохраняются: Radix Dialog, Lucide React, Motion, React 19, CSS Modules. Переходы применяются только к демонстрационной карточке участника, а не к пьедесталу.

Размеры текста повторяют плотность эталона; мелкие подписи и белые цифры на металлах не следует считать автоматически соответствующими WCAG. Это согласованное визуальное воспроизведение, не сертификация доступности.

## Разработчику

Готовый файл: `dist/tengu-rating-v2.html`. Исходники: `src/Rating.tsx`, `src/Rating.module.css`. Встроенные шрифты и библиотеки обеспечивают работу без внешних запросов. `participants` — демонстрационные данные. При встраивании реальных аватаров необходимо указать `avatarUrl`; компонент уже показывает одно изображение и в пьедестале, и в строке, а также обрабатывает ошибку загрузки.

Пересборка: `npm ci`, `npx tsc`, `npm run build`. Папка assets содержит все текущие шрифты и лицензию Manrope. Реальные маршруты приложения, уведомления и данные сервера в этом прототипе не подключены.

Проверка: TypeScript без ошибок; Chromium 320, 360, 390, 430, 768, 1440 px; нет горизонтального переполнения и внешних запросов. Диалоги, Escape, возврат фокуса и режим reduced motion работают. Последняя строка достижима прокруткой и не скрывается нижней навигацией в конце страницы. Высота кнопок вкладок 40 px соответствует образцу.

Подробное исследование библиотек и прежняя версия макета доступны в истории ветки `design/rating-v2`.
