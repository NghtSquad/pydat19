# Фитбэк

Адаптивный сайт с игрой про скалолаза. HTML, стили, скрипты и шрифт Manrope встроены в `index.html`; внешний доступ не требуется.

## Открыть сайт

Скачайте `index.html` через кнопку **Download raw file** на GitHub и откройте его в браузере. Или запустите локальный сервер из корня репозитория:

```sh
python -m http.server 3000
```

Сайт будет доступен по адресу `http://localhost:3000/fitback/`.

## Игра

Клики поднимают скалолаза и дают монеты. Скальники увеличивают высоту за клик, магнезия — монеты, страховка — автоматический подъём. Вершина на 100 м даёт бонус. Состояние сбрасывается при перезагрузке страницы.

Форма проекта скачивает бриф локально; отправка заявок не подключена. Персонаж — прототип, палитра взята из присланного изображения; интеграция полного брендбука Figma ожидает доступа к нему. Лицензия Manrope включена в HTML.
